# Gates: E2.3 JIT-vs-interpreter differential stress (random program corpus)

Scope: E2.3 owns `crates/bamts-codegen/tests/jit_differential.rs`; it delivers JIT-vs-interpreter differential stress with deterministic seeded programs and explicit tiering/lifecycle vectors.

The test target is feature-gated with `host-jit`; it uses the real verified bytecode program, interpreter, Cranelift JIT, runtime native-entry driver, helper classifier, and tiering state machine. It contains no fake entry table, mocked helper, ignored test, time-based wait, or fallback implementation.

## Contract vectors

| Test | Observable contract |
|---|---|
| `every_classified_opcode_and_helper_is_accounted_for` | The 58-entry append-only ISA representative table has no missing helper demand, the structural fuel helper is included, and the reached external indices equal the complete 52-helper runtime namespace. |
| `deterministic_seeded_arithmetic_matches_interpreter` | Eight fixed 64-bit seeds × 20 operators × two independent native publications produce the same stdout, exit status, and abrupt result as the interpreter. Failure messages retain seed, operator, and operands. |
| `branches_moves_and_normal_completion_match_interpreter` | Inline move/jump/conditional control flow and normal completion agree across engines. |
| `abrupt_throw_and_fuel_deopt_match_interpreter` | Uncaught throws and exact fuel exhaustion compare the full `RuntimeError` (kind, value/origin, function, pc, and source instruction), not merely “both failed.” |
| `osr_deopt_and_cancellation_are_exact_and_terminal` | Baseline/optimized thresholds, true-back-edge OSR, forward-edge rejection, deopt pinning, and idempotent terminal cancellation fire at exact counts. |
| `executable_publication_is_repeatable_and_program_bound` | Repeated compile/run/drop cycles publish a finalized JIT artifact bound to the exact canonical program bytes; a `JitProgram` cannot exist before its private W^X provider mints `FinalizedMemory`. |

## Mutation checks

These are load-bearing mutations; each names the test that must fail. Apply one at a time and restore the file before the next probe.

1. In `assert_differential`, replace `assert_eq!(actual, expected, ...)` with `assert_ne!(actual, expected, ...)` → seeded, branch, and abrupt differential tests fail.
2. In `Lcg::next`, change the increment from `1_442_695_040_888_963_407` to `1_442_695_040_888_963_408` → the deterministic corpus changes; the registered content-addressed receipt becomes stale and the evidence aspect fails.
3. Change `ISA_REPRESENTATIVES.len(), 58` to `57` → `every_classified_opcode_and_helper_is_accounted_for` fails.
4. Remove `STRUCTURAL_HELPERS` from the reached set → helper accounting fails on `Helper::ConsumeFuel`.
5. Change the OSR loop bound from `policy.osr_back_edges - 1` to `policy.osr_back_edges - 2` → exact-threshold OSR assertion fails.
6. Change the deopt policy budget from `2` to `3` → the pin assertion fails.
7. Delete `cancelled.cancel()` calls → cancellation terminality assertion fails.
8. Compare `compiled.program_bytes()` to an empty slice → executable publication/program-binding test fails before native entry.
Observed mutation proof: mutations 3–8 each failed the named assertion under the narrow integration target, were restored immediately, and the complete target then returned `6 passed; 0 failed; 0 ignored`.
